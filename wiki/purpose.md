# 🎯 Purpose - My Knowledge Base

## Obiettivo Principale
Creare una knowledge base personale centralizzata che mi permetta di:
- **Preservare** tutte le mie idee, progetti e conoscenze
- **Accedere** da qualsiasi dispositivo e agente AI
- **Trovare** rapidamente informazioni quando mi servono
- **Connettere** concetti e idee apparentemente scollegati

## Domande Chiave
1. Come posso organizzare al meglio le mie conoscenze?
2. Quali sono i pattern ricorrenti nei miei progetti?
3. Come posso riutilizzare soluzioni già trovate?
4. Quali sono le lacune nelle mie conoscenze?

## Scope della Knowledge Base

### 📚 Conoscenza Tecnologica
- Framework e librerie (React, Vue, Next.js, ecc.)
- Backend (Node.js, Python, Rust, Go)
- DevOps (Docker, Kubernetes, CI/CD)
- Database (SQL, NoSQL, Vector DB)
- AI/ML (LLM, RAG, Agenti)

### 💡 Progetti Personali
- Web app
- Mobile app
- CLI tools
- Librerie condivise
- Script di automazione

### 📖 Studio e Ricerca
- Paper tecnologici
- Articoli e tutorial
- Libri e documentazione
- Best practices

### 🧠 Riflessioni e Strategie
- Architettura software
- Design patterns
- Processi di sviluppo
- Gestione del tempo
- Produttività

## Lingua
- **Primario**: Italiano
- **Secondario**: Inglese (per documentazione tecnica)

## Formato
- **Markdown**: per massima compatibilità
- **Obsidian**: per visualizzazione a grafo
- **YAML frontmatter**: per metadati strutturati

## Aggiornamento
- **Frequency**: almeno una volta a settimana
- **Trigger**: nuovi progetti, scoperte, riflessioni
- **Review**: mensile per eliminare obsolescenza
